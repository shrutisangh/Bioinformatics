# Bioinformatics

**MSc Big Data Analytics** · Jai Hind College (Autonomous), Mumbai · Shruti Sanghavi

A journal of hands-on bioinformatics work: searching the literature, exploring sequence databases, aligning sequences, running similarity searches, multiple sequence alignment, and an integrated protein analysis of human p53. Each topic has its own folder with the aim, observation tables, results, discussion, conclusion and viva questions with answers.

## Folder layout

Each folder contains a `README.md` with these sections: Aim, Tools, Observations, Results, Discussion, Conclusion, Viva Questions and Answers, Checklist and Notes for review. Folders 09 and 12 also contain the runnable commands and files (`run_msa.sh`, `p53_structure.pml`, `p53_tree.nwk`).

## About the notes

Tables and answers come from the written journal. Where a value looked inconsistent with the source database, it is corrected in the table and the original entry is listed under **Notes for review** at the end of that README. Screenshots from the journal are not included in this repository.
